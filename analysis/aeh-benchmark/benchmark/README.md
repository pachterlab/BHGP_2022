# Ahlmann-Eltze and Huber benchmark framework

This folder contains the adapted benchmark framework used for the consistency,
simulation, and downsampling analyses.

## Run the benchmark

To re-run the benchmark, call:
```{bash}
$> Rscript src/run_benchmarks.R
```

The script reads `job_overview.yaml`, which defines the parameters for each
benchmark.

The project uses a custom `.Rprofile` generated by [renv](https://rstudio.github.io/renv/articles/renv.html) 
which makes sure that the correct version of each package is used.

Depending on the execution environment, it may be necessary to set output or
tool paths:
* set `SANITY_FOLDER` to the Sanity installation directory if running Sanity
  transformations.
* set `.OUTPUT_FOLDER` in `src/run_benchmarks.R` if the default benchmark output
  location is not appropriate.

Set up the virtual Python environment for _normalisr_ once with:
```R
reticulate::virtualenv_install("normalisr_python_env", packages = "normalisr")
```

The benchmark job scheduler is implemented in `src/job_management_utils.R` and
is designed around the Slurm workload manager.

## Collect results

After all jobs have finished, collect the results with:
```{bash}
$> Rscript src/collect_results.R
```
Results are stored in `output/benchmark_results/`.

## Interesting files

* [`src/transformations/transformation_helper.R`](src/transformations/transformation_helper.R) contains a function for each transformation and is the best reference for how each transformation is called.
* [`src/consistency_benchmark/calculate_10X_consistency.R`](https://github.com/const-ae/transformGamPoi-Paper/blob/master/benchmark/src/consistency_benchmark/calculate_10X_consistency.R), [`src/downsampling_benchmark/calculate_downsampling_agreement.R`](https://github.com/const-ae/transformGamPoi-Paper/blob/master/benchmark/src/downsampling_benchmark/calculate_downsampling_agreement.R), 
and [`src/simulation_benchmark/calculate_ground_truth_overlap.R`](https://github.com/const-ae/transformGamPoi-Paper/blob/master/benchmark/src/simulation_benchmark/calculate_ground_truth_overlap.R) calculate the overlap metrics for the three benchmarks, respectively.
* [`src/simulation_benchmark/simulate_with_XXX.R`](https://github.com/const-ae/transformGamPoi-Paper/tree/master/benchmark/src/simulation_benchmark) contain the code to simulate data with the five simulation frameworks

## Internal workflow management

The benchmark uses a workflow management system built around
[Slurm](https://slurm.schedmd.com/documentation.html). Workflow management is
implemented in [`src/job_management_utils.R`](src/job_management_utils.R); it
stores intermediate results and avoids rerunning scripts when the script and
input arguments have not changed.
